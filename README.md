# 割り勘アプリ 操作手順

動画で行っている操作を、順番に書いています。

## 準備

デモデータを入れた状態から始めます。

```bash
sail artisan migrate:fresh --seed
```

ログインに使うアカウントは次の2つです。パスワードはどちらも `password` です。

| 名前 | メールアドレス | 使うウィンドウ |
|---|---|---|
| Test User | test@example.com | ふだんのウィンドウ |
| 鈴木 | suzuki@example.com | シークレットウィンドウ |

## 操作

1. Test User でログインすると、マイページが開きます。上段に「払う 11,550円」「受け取る 16,250円」「グループ 2件」が表示されます。その下には、自分が払う精算と受け取る精算の一覧と、グループごとの自分の残高が並んでいます。
2. マイページの「グループ」から「別府旅行」を開きます。支払いの記録、精算の一覧、メンバーごとの残高を確認します。
3. 「支払いを記録」を押し、何に「お土産」、金額 3,000円、払った人 Test User、誰の分は田中と佐藤だけにチェックを入れて記録します。支払いの一覧に「田中、佐藤の分」として追加され、精算の金額が変わります。
4. 精算の一覧から1行を選び、「精算した」を押します。その行が精算の一覧から消え、支払いの記録に「精算」のバッジが付いた行が増えます。
5. 鈴木としてログインし、「ゼミ合宿」を開きます。精算の一覧にある「Test User → 鈴木 11,550円」の「精算した」を押します。
6. Test User のウィンドウに戻り、マイページを読み込み直します。「払う」が 0円 になっています。
