# 割り勘アプリ 操作手順

動画の中で行っている操作を、順番に書いています。

## 準備

次のコマンドで、デモデータを入れた最初の状態にします。

```bash
sail artisan migrate:fresh --seed
```

ログインには次の2人を使います。

| 名前 | メールアドレス | パスワード |
|---|---|---|
| Test User | test@example.com | password |
| 鈴木 | suzuki@example.com | password |

## 1. マイページを見る

- やること: Test User でログインする
- 見えるもの: 上段に「払う 11,550円」「受け取る 16,250円」「グループ 2件」

## 2. 別府旅行を開く

- やること: マイページの「グループ」から「別府旅行」を押す
- 見えるもの: 支払いの記録、精算の一覧、メンバーごとの残高

## 3. 支払いを記録する

- やること: 「支払いを記録」を押し、次のとおり入力して「記録する」を押す

| 項目 | 入力する内容 |
|---|---|
| 何に | お土産 |
| 金額 | 3000 |
| 払った人 | Test User |
| 誰の分か | 田中と佐藤だけにチェック |

- 見えるもの: 支払いの記録に「お土産」の行が増え、「Test Userが払った ・ 田中、佐藤の分」と表示される。精算の金額も変わる

## 4. 精算したことを記録する

- やること: 精算の一覧の「田中 → Test User 4,250円」で「精算した」を押す
- 見えるもの: その行が精算の一覧から消え、支払いの記録に「精算」のバッジが付いた行が増える

## 5. 鈴木として精算を記録する

- やること: 鈴木でログインし、「ゼミ合宿」の精算の一覧にある「Test User → 鈴木 11,550円」で「精算した」を押す
- 見えるもの: その行が精算の一覧から消える

## 6. Test User のマイページを確かめる

- やること: Test User の画面に戻り、マイページを読み込み直す
- 見えるもの: 「払う」が 0円 になっている
